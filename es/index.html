Cómo trabajamos

Crear, añadir, mejorar.

El claim de la marca es literalmente el método: se publica algo pequeño que ya sirve, y a partir de ahí se crece sobre algo vivo.

PASO 01

Crear

Empezamos por la versión más pequeña que resuelve el problema de verdad. Nada de meses de proyecto antes de ver algo funcionando.

PASO 02

Añadir

Lo que se añade después sale del uso real, no de una lista escrita antes de empezar. Se paga lo que se usa.

PASO 03

Mejorar

La aplicación sigue viva: se corrige, se afina y se adapta a lo que el negocio necesite más adelante.
